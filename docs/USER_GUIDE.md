# Vector Drift — macOS Help

Arcade space combat — Classic, Modern and 3D Flight

## How to play

Survive waves of asteroids, saucers and environmental hazards while managing shields and weapons. Choose Classic, Modern, or 3D Flight and difficulty from the in-game toolbar.

## Keyboard and mouse controls

| Control | Action |
|---|---|
| Return | Start or restart from title or game-over screen. |
| Left / Right | Turn or yaw. |
| Up | Thrust forward. |
| Down | Hyperspace in 2D; reverse in 3D Flight. |
| Space | Fire weapon. |
| S | Shield. |
| N | Launch available special missile. |
| P | Pause or resume. |
| 3D Flight: I/K, Q/E | Pitch; roll. |
| 3D Flight: W/X, A/D | Rise/dive; strafe. |

## Scores, saves and settings

Custom rules, saved games and score records are stored locally, not in GitHub. Use the in-game Save Game and Resume commands; switching display modes does not upload your progress.

## Application menus

The native **Game** menu offers How to Play, Controls & Shortcuts, and Scores & Saving. The **Help** menu opens these offline instructions. Standard macOS App, Edit, Window, and Quit commands remain provided by the operating system. In-game gameplay buttons and shortcuts are unchanged.
